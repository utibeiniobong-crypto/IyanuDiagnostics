Dream Diagnostics · Android

Take Iyanu Dream Diagnostics with you.

Use the Android app as another access point to the Iyanu Dream Diagnostics ecosystem. The web tool, WhatsApp service, Android app and Dream Dictionary are designed to work as complementary resources.

Download Android App ↗Open Web Dream Diagnostics →

1. Download

Tap the download button and open the Google Drive file.

2. Install

On Android, open the downloaded APK. If Android asks for permission to install from that source, allow it for your browser/file manager and continue.

3. Explore

Use the app alongside the web Dream Diagnostics and Dream Dictionary as you study and reflect.

Important: Android may display a security warning for an APK installed outside Google Play. Only install the file if you trust its source. If installation is blocked, check Android's settings for permission to install unknown apps for the app you used to open the APK.
